CaluServers uses independent integrations: WHM API 1 via WHM_SERVER_URL, WHM_USERNAME and WHM_API_TOKEN (environment variables in Vercel) for read-only cPanel account listings in /admin/whm; WHMCS Identifier and Secret in /admin/settings for billing.
